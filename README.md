# Smart Student Planner

A beginner-friendly Student Planner web application built with HTML, CSS, and JavaScript.

## Features
- Add study tasks, assignments, exams, and personal tasks
- Set a subject, due date, and priority
- Mark tasks as completed
- Filter tasks by all, remaining, or completed
- Delete tasks
- View total, completed, and remaining task counts
- Automatically save tasks in browser LocalStorage
- Responsive layout for mobile and desktop

## How to run
1. Download and extract the ZIP file.
2. Open the `student-planner-saas` folder.
3. Double-click `index.html` to open it in a web browser.
4. Add your first task.

No installation or server is required for this beginner version.

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Important note
This is a front-end prototype, not a full multi-user SaaS product yet. A future version could add login, a Python Flask backend, a database, cloud synchronization, and reminders.

## Upload to GitHub
1. Create a new repository named `student-planner-saas` on GitHub.
2. Extract this ZIP.
3. Upload the files and folders to your repository, or use Git:
   ```bash
   git init
   git add .
   git commit -m "Add Student Planner project"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/student-planner-saas.git
   git push -u origin main
   ```
   Replace `YOUR-USERNAME` with your GitHub username.
